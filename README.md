### <font color="#6366F1">📊 Análises no Excel</font>

#### <font color="#3B82F6">🔹 Empresas Multimodais (ANTT)</font>
<font color="#4B5563">Análise de dados abertos da ANTT para mapeamento das empresas habilitadas no setor.</font>

* **Fórmula utilizada:** `CONT.SE`
* **Questões analisadas:**
  * <i>Qual estado possui o maior número de empresas habilitadas?</i>
  * <i>Qual país (exceto o Brasil) tem a maior presença de empresas?</i>

#### <font color="#3B82F6">🔹 Chegada de Turistas no Brasil (gov.br)</font>
<font color="#4B5563">Estudo sobre o fluxo turístico nacional a partir da base de dados do portal gov.br.</font>

* **Fórmula utilizada:** `SOMASE`
* **Questões analisadas:**
  * <i>Qual via de acesso foi a mais utilizada?</i>
  * <i>Qual estado registrou o maior fluxo de visitantes?</i>
  * <i>Qual mês teve a maior concentração de turistas?</i>
